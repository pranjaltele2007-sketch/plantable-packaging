# Plantable Packaging 🌿
> **"Packaging That Doesn't End Up in Landfills. It Blooms."**
> Entrepreneurship Milestone 1 Project by **Rudra Morkhade** (Alandi, Pune, India)

100% biodegradable, home-compostable seed paper boxes engineered for sustainable D2C brands, organic cosmetics, and artisanal soaps.

---

## 🚀 Live Preview / Quick Start

You can open and view this website immediately:

### Option 1: Double-Click
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or any modern browser.

### Option 2: Local HTTP Server
Run either of these commands in PowerShell inside this directory:

```bash
# Using Python
python -m http.server 8000

# Or using Node / npx
npx serve .
```
Then visit: `http://localhost:8000`
